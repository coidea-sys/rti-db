## Notes

- v0.8 adds segment compaction, multi-shard Raft, and the public O(1) `latest()` index. The first bench run of this wave showed a -10.4% batch-ingest regression traced to a per-record mutex+hashmap update of the latest index on the ingest thread; the merged fix coalesces latest-index updates to one lock per batch (zero heap allocation in steady state, alloc-count audited).
- `latest()` itself is O(1) with zero heap allocation on the read path; its micro-benchmarks live in `crates/rti-vla/tests/latest_perf.rs` (reporting p99/mean, non-gating on shared CI).
